# Forge

Forge is a local project scaffolding CLI for Friday.

It creates new projects from templates and standardizes:
- folder layout
- README files
- runbooks
- Jenkinsfiles
- Docker Compose files
- interview/demo documentation

## Goal

Reduce project startup friction and make every new project production-style from day one.

## Initial Scope

Forge v0.1 will support:
- creating a project folder
- selecting a template
- rendering template files
- initializing Git
- generating docs
- printing next commands

## Future Scope

Later versions may integrate with:
- Gitea
- Jenkins
- n8n
- Coder workspaces
- StarkGrid project indexing
