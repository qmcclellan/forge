# Forge Runbook

## Purpose

Forge is a local project scaffolding CLI for Friday.

## Local Setup

Run:

    cd /srv/workspaces/projects/portfolio/forge
    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install --upgrade pip
    python -m pip install pytest

## Run Tests

Run:

    python -m pytest

Expected result:

    2 passed

## CLI Smoke Test

Run:

    python3 -m forge.cli --help
    mkdir -p /tmp/forge-test
    rm -rf /tmp/forge-test/hello-worker
    python3 -m forge.cli new hello-worker --template python-worker --output-dir /tmp/forge-test
    cat /tmp/forge-test/hello-worker/README.md

Expected README output:

    # hello-worker

    Generated by Forge using template `python-worker`.
